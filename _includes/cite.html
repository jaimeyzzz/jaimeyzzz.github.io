{%- comment -%} Inline citation. Usage in a post body: {% cite some_key %} Renders a superscript [n] linking to the matching entry in the post's `references:` front-matter list (numbered by its position in that list). {%- endcomment -%} {%- assign _key = include.key -%} {%- assign _num = 0 -%} {%- for r in page.references -%} {%- if r.key == _key -%}{%- assign _num = forloop.index -%}{%- endif -%} {%- endfor -%} {%- if _num > 0 -%}{{ _num }}{%- else -%}[?]{%- endif -%}
